Feature-Based Estimation ทำงานอย่างไร

  • แตกระบบเป็น 18 functional module ที่ส่งมอบ/ตั้งราคาแยกได้ อ้างอิงจาก LOC, จำนวน endpoint และความซับซ้อนจริงในโค้ด
  • ตีขนาดแต่ละโมดูลเป็น man-day แล้วคูณ เรตตลาดไทย 9,000 บาท/วัน (software house เฉลี่ย junior→senior)
  • บวก PM / Overhead 15% (requirement, coordination, deployment)
  • ทำ scenario ต่ำ–สูง ที่ 7,000–12,000 บาท/วัน
  • เทียบแต่ละ function กับ SaaS ในตลาด (Jira / Monday / Asana) ว่าซื้อสำเร็จรูปแทนได้ไหม

อ้างอิงเรต: เงินเดือน dev ไทย ~35k–162k บาท/เดือน, เรตชั่วโมงเฉลี่ย ~570 บาท → เรต billed ของ software house เฉลี่ย ~9,000 บาท/man-day
